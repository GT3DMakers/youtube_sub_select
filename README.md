# YouTube Subs Cleaner
Masque les vidéos vues (≥ 90 %) et les Shorts sur youtube.com/feed/subscriptions.

Mise à jour : clic droit sur `update.ps1` → « Exécuter avec PowerShell », puis « Recharger » dans `brave://extensions`.

Installation (Brave) : `brave://extensions` → activer « Mode développeur » → « Charger l'extension non empaquetée » → choisir ce dossier.
